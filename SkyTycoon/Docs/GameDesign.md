# 晴空地产：玩法策划 v0.2

开发基线，不代表成品验收。采用 UE 5.7.4；最终微信发布链路尚未验证。

## 模式和人数

每局 2～4 席位，真人与人机共用上限。支持目标为最多 4 真人联机，以及真人与人机混合。当前为本机模式，默认 1 真人 + 1 普通人机；联机、云存档和玩家地图编辑器待实现。

人机没有额外资源或骰点加成，只使用公开信息决定购买。简单保留现金 2500，普通保留 1500，困难保留 max(800, 对手最高租金×2)。人机默认每 0.8 秒执行一步，客户端右上角可切换 2×（0.4 秒）；不改变真人操作时间、随机概率或规则。三种策略的实际强弱尚未做统计验证。

## 基础规则

当前席位选择道具与骰子 → 投掷 → 逐格移动并触发陷阱 → 跨起点发工资 → 结算落点 → 可购买/入住或跳过 → 结束回合。

普通玩家默认两颗骰子亮起，可选择 1～2 颗；汽车生效时最多 3 颗，使用汽车时三颗全亮。每颗按钮点击切换亮/灭，亮的参与投掷，至少保留一颗；普通玩家第三颗锁定。汽车到期时裁剪第三颗选择，保证至少一颗。每颗均为六面骰，总步数相加。人机默认使用当前最大颗数。遥控骰子独立选择最终 1～6 步，覆盖普通/汽车掷骰总和，但仍消耗一次汽车移动次数。

无人地产按标价购买，他人地产收租；自有地产暂不升级。机会随机 +500 或 -400；休息格无效果。现金小于零破产，地产回收为无主，现金归零。租金债权人最多收到破产者实际现金。最后一名未破产玩家胜利。

## 商店、设施与道具（本地版本已实现）

默认地图的 4、16 号格为商店，落点打开商店，每次到访最多购买一件。背包最多 8 件，可重复持有；价格固定、库存无限，资金不足或背包已满拒绝购买且不扣钱。购买后离店结束回合。首版不提供出售或丢弃。

每回合投掷前最多使用一件道具；处于拘留/住院阶段只允许对应的恢复道具。失败操作不消耗道具或使用次数。护盾与免租卡不重复叠加，激活后保留至触发；所有人可查看陷阱。

炸弹和路障只能放在前方 1～6 格的空道路上：不能占用起点、设施或有玩家的格子，不能覆盖已有陷阱。逐格触发，包括汽车移动；放置者本人也会触发。炸弹触发后消失，扣 600 医疗费并送医院，后续休养两个自己的回合；护盾抵消一次炸弹并继续移动。路障触发后消失，停止在该格并正常结算地产等效果。

20 号逮捕格送往 6 号监狱，之后停留两个自己的回合。落在监狱本身只是探访，不入狱。12 号医院仅收治炸弹伤者，正常路过/落点不强制住院。入院/入狱传送不发工资，取消汽车和未用的遥控步数，不再次结算设施格。自定义地图缺少对应设施时原地停留，仍执行恢复规则。

抵达当回合结束，但不扣停留回合；以后每次选择等待消耗一个自己的回合。等待最后一次后，下一次轮到自己才能移动。可支付保释金 800 / 加急治疗费 600，或使用出狱卡/医疗包立即恢复当前回合投掷。加急治疗费与炸弹入院费分别收取。停留期间自有地产仍正常收租。

18 号旅店提供入住或免费离开。入住扣 300，赠一层炸弹护盾，之后休息一个自己的回合；汽车剩余次数不随休息减少。入住后不能付费跳过休息，医疗包/出狱卡不能用于旅店。已有护盾不叠加。

完整价格和效果见 BalancePlan.md。人机会购买道具、优先使用匹配恢复卡、清障和防御，再尝试陷阱、遥控骰子或汽车；陷阱策略尚为基础启发式，可能承担自踩风险。

## 联机设计（待实现）

房间状态：等待 → 对局 → 结算 → 关闭。房主选择地图版本、总人数、人机席位和难度，真人准备后开局。服务端同时限制真人数与总席位数不超过 4，满员拒绝加入。开局冻结地图快照，不允许临时编辑改变对局。

操作携带对局 ID、操作 ID、预期状态版本和操作类型。服务端鉴权、检查当前席位和阶段，生成骰点及事件，执行规则并广播结果。重复请求返回同一结果；版本冲突返回最新快照。人机在服务端使用相同规则。

断线设计提案：单次操作限时 30 秒，身份保留 60 秒后人机暂管；重连玩家在下一回合取回控制。服务端保存房间，房主退出不销毁对局。时限需弱网测试后定版。

## 地图定制

当前数据支持 8～128 格，16×16 坐标范围，数组顺序为路径，第一格唯一 Start，首尾闭合、正交相邻且无重复坐标。名称、类型、地价、租金、工资和初始现金可配置。

计划编辑器流程：创建草稿 → 绘制路径 → 配置格子 → 校验 → 试玩 → 保存版本。云端保存作者、地图 ID、版本和内容摘要。修改发布地图产生新版本，不影响正在进行的比赛。自定义经济地图按娱乐模式处理。

## 云端数据

计划保存用户设置、地图草稿与版本、对局配置、玩家资产、回合状态和人机难度。云端按用户身份隔离；在线对局以服务端数据为准，本地存档不得覆盖在线结果。版本检查防止并发覆盖，操作 ID 保证失败重试不会重复扣款。

云服务商和身份认证尚未接入，也没有上传任何用户数据。

## 实施与验收

1. UE 本地原型：编译、规则测试、完整人机对局、中文触控 UI。
2. 地图编辑器与版本化保存：无效地图拒绝保存，重开内容一致。
3. 权威联机：2/3/4 人客户端验证，第五人拒绝；测试重复操作、乱序、断线重连和人机接管。
4. 云端存档：权限隔离、并发冲突与网络中断恢复。
5. 原创资源、数值调优与微信真机发布适配。

微信最小场景导出必须尽早验证。UE 桌面编译和运行不能证明微信兼容。
