## 按住、确认与取消

- 默认指向技能按住预览，松开开始实际施法；键鼠也可左键确认。左键确认后松开原技能键不会再放一次。鼠标单独控制P2时，左键按住预览所选技能、松开确认。
- ESC → 画面与性能 → 指向技能触发，可改成按下开始施法。选择自动保存，双人共享本机偏好。两种模式控制何时开始原有前摇，不跳过前摇、价格、冷却或判定。
- 火球、闪电、锁链为浅色方向通道，火焰喷射为扇形；闪现为目标圈，流星为实际影响半径圈。前者按已有射程/散布计算；闪现提示同步避让柱体。材质以低透明度填充、细边和像素导数过滤显示，不覆盖大块画面。
- 天罚、护盾/急行是自身施法，直接按下，没有目标图形。已连接锁链的再次按下仍立即断开。
- S（可改键）、鼠标中键、右摇杆按下R3取消；右键移动也取消。预览期间不扣生命、不进入冷却、不产生释放音效。实际前摇开始后沿用S/R3取消规则，已经释放的技能不能撤回。
- 暂停、死亡、准备/战斗以外阶段、打开商店/帮助、换设备会清理预览。换设备清理在刷新按键映射之前执行，避免松键触发旧预览。
- 引导组件由对应Pawn拥有并设置OnlyOwnerSee；左右分屏中各看自己的引导。手柄仍沿左摇杆保留的朝向施法，未增加右摇杆瞄准。

每位玩家最多一个持续更新的无碰撞引导网格，不进行额外命中检测，不引入Tick粒子阵列。表现不参与权威伤害、碰撞、范围和经济计算。
