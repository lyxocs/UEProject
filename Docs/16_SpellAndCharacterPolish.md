# 技能表现与角色第二轮细化

2026-11-26。按用户试玩反馈继续修改，当前规格覆盖第15章中火球速度与首轮粒子表现。伤害、冷却、经济和碰撞范围仍使用既有规则；没有采购额外美术包。

## 视觉与动作

| 技能 | 当前表现 |
|---|---|
| 火球 | 隐藏原实心发光球，以6层持续卷动火焰组成主体，辅以30个有寿命的火舌/火星粒子；外围火焰更大，碰撞仍为原25半径 |
| 天罚 | 扩散到250半径的双层冲击环、符纹、48个径向粒子；举杖到落杖，保留0.7秒可取消前摇 |
| 闪电 | 主电弧、分叉电弧、接触火星，替代原来的一串实心小圆盘 |
| 闪现 | 三道复制当前骨骼姿态的半透明残影、沿路径分散的紫色粒子和起点符环 |
| 火焰喷射 | 每发使用较小的火焰主体与火舌拖尾，保持连发间隔与伤害 |
| 流星 | 提前显示落点符环，并有从高处下降的火焰粒子团；命中时生成独立爆发与扩散环 |
| 反射盾 | 低透明度的薄边护盾、动态明暗切面，以及启动时的符纹与粒子；保护泡不再遮住整个人物 |
| 锁链 | 飞行阶段蓝色能量粒子，附着后显示持续更新的能量系带；断开/死亡后清理 |

全部技能前摇增加分色手部蓄能粒子和脚下符环。特效事件通过 `AWarlockSpellFX` 发送与表现；它不计算伤害，也不决定命中或奖励。复制与多人完整表现仍需要网络实测。

施法动画改为抬手、释放、收势三个阶段：前摇时间映射到各动画的接触姿态，释放后按自然速度收势并淡回待机，避免将整段动画在零点几秒内快速播完。天罚/流星在站立施法时混合下半身动作；其他技能保留上半身施法。取消保持最后姿态淡出，前摇锁定面向施法目标。

## 弹速

火球单独使用 `FireballSpeedScale=0.60`，即600单位/秒，比上一轮780再慢约23%；寿命相应延长，约保留原1000单位射程。喷射、锁链仍为 `ProjectileSpeedScale=0.78`。参数位于 `Config/DefaultGame.ini`。更大的火焰与光晕是视觉范围，不扩大碰撞。

## 角色

之前按贴图文件名将全部 Hero_BloodElf 区域当成金属，其中包含大块衣服和斗篷。现在只保留真正的护甲部分使用金属，主体使用布料，靴子更深；恢复赤曜酒红、霜月藏蓝、幽林墨绿三套配色。衣料加入适度织纹、褶皱法线和边饰；降低大块金属与宝珠的亮度，头饰缩小。

`Scripts/refine_character_mesh.py --polished` 从原始对照GLB派生新网格：细化21个区域，1022→10940个三角形，包含之前未处理的大块斗篷、护甲与面部区域；保留51骨骼、UV、权重与六段源动画。新资产在 `Characters/PolishedWarlock`，旧 SourceWarlock、RefinedWarlock 和原地图保留。此轮是源模型细化与材质修复，不冒充全新高清雕刻角色。
