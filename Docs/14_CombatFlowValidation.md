# 战斗流程与动作回归

2026-11-26。范围是当前四席位样机（八个基础技能），不是原地图全部技能变体的验收。原地图保持只读；没有运行 Warcraft III。

## 本轮修正

- 保护期不能直接忽略命中。原脚本 AN/IN 为保护者设置/恢复 0.1 伤害和击退倍率，PN 先加冲量，GN 再阻止被保护目标的生命、K、贡献与吸血变化。UE 现在保留这一顺序：目标保护时承受 10% 外力；攻击者保护时输出 10% 伤害；双方都有保护时外力为 1%。不借此改变伤害或经济平衡。
- 行走速度取实际主动位移，扣除外力并经过柱体约束；顶住柱子或单纯被击退不播放跑步。移动转向采用每秒 720 度的过渡，施法仍立即对准目标；保留原伤害与弹速。行走、上半身施法、死亡使用现有骨骼动画。
- 每个本地 HUD 独立显示头顶生命条、姓名和 K。底部生命保留一位小数，避免岩浆小额伤害被整数遮住；实际血量即时更新，金色损失段停留 0.25 秒后追上，仅改变表现。
- 死亡后本地镜头平滑跟随存活者，合作优先跟随队友；新回合恢复自己的镜头。回合结束清空主动行走、连发与锁链状态。
- 重开清理残留飞弹、脉冲、模拟计时器和技能模式，同时保留外观选择。终局显示胜者姓名/队名与积分，支持 Enter/Menu 或点击“再来一场”；加赛显示正确的回合名称。
