# 客户端画面与性能

## 操作和保存

右上角常驻平滑FPS及毫秒帧时间，单人、左右／上下分屏、准备、战斗和暂停均保留；每个本地视口各显示一份。显示的是客户端帧率，不是服务器模拟频率。Esc/Menu暂停，点击「画面与性能」或按Tab/手柄X切页；↑↓选择、←→调整，鼠标可点左右箭头。Esc/Menu继续游戏。原AI档位入口及数字1至5仍在AI页，避免与画质导航冲突。

十项设置：五档预设、窗口分辨率、窗口／无边框、场景渲染比例50/67/75/85/100%、帧率上限30/60/90/120/144/165/240/不限、垂直同步、阴影、全局光照、反射、特效。切换分辨率进入窗口模式；无边框使用桌面分辨率，低于桌面渲染通过场景比例实现，不将无边框下无效的窗口尺寸当成降分辨率。无独占全屏切换。即时生效并自动保存到本机GameUserSettings，双人共享，不复制到服务器／存档。

新安装默认均衡、120FPS上限、VSync关闭。旧版已保存的分辨率、窗口、画质、比例、帧率上限和VSync迁移保留，不每次启动覆盖玩家选择。UGameUserSettings派生类统一处理首次启动、加载、F6/F7、菜单与保存，避免三条路径互相覆盖。旧版原有60FPS上限仍会保留，升级后可在菜单改为120或不限帧。VSync开启时还会受显示器刷新率限制；上限不能保证实际达到该帧率。

v0.9清晰度调整：低配/流畅使用高质量TAA，均衡/高画质使用均衡TSR，精细使用精细TSR；新增独立抗锯齿行。场景宽度预算分别1600/1920/2560/3840/3840，比例最低50%；手动比例可覆盖。首次启动按即将应用的桌面分辨率预算，不按启动临时小窗口误判4K成本。UI按输出像素绘制，不随场景比例变模糊。旧版下方性能数据仍对应旧比例，不作为v0.9帧率承诺；新验证见[第26章](26_RenderingClarity.md)。UE5.9本机BaseScalability.ini的中档GI已是简化Lumen，不能套用旧引擎“中档一定关闭Lumen”的假设。

低档保留全部技能前摇、预警圈、闪电／锁链、火球核心和命中方向，只减少装饰密度。新发射／新生成特效按当前档位创建，已有短时效果自然结束；场景漂浮火星即时调整。伤害、碰撞、击退、弹速、技能范围、AI与0.03秒固定步不随画质或帧率改变。高画质画面保留，不用永久关闭光影来声称同画质性能大幅提升。

客户端开销修整：主题颜色收敛后停止重复提交相同材质参数；危险边界只在变换变化时更新；柱体只在显隐变化时提交；隐藏的装饰火星停止逐个变换与材质更新；低档降低大量独立半透明组件及尾迹更新预算。没有修改原地图或玩法数值，也没有以改游戏速度换取高FPS。

## 验证

编辑器完整反射／C++编译、Game编译及Windows打包验证；资产未改动，复用上一版已完整Cook的内容。37项新增PIE检查覆盖五档、保存重载、上下限、VSync、暂停键盘／手柄菜单路由、共享设置和装饰粒子显隐；相关准备36、特效21、设备24、AI暂停17、完整11轮／加时流程88项重新通过，合计223项。实体手柄、另一台PC及持续高负载实战不冒充已验收。

实际独立客户端重启测试、最终画面和性能结果见下方记录及Saved/Validation对应报告。脚本ProfileClient.ps1固定1600×900、关闭VSync和帧率上限、1200帧采样丢弃前300；左右分屏两个人类席位静止、两个AI活动。不同运行的AI过程不是逐帧相同回放，短测不代表帧率下限或其他电脑保证。主要瓶颈在GPU／渲染线程，减少重复更新的CPU优化不等同于同画质帧率翻倍。
