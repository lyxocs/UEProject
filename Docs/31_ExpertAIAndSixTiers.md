# 六档AI与宗师训练

第六档「宗师」使用独立的 `ExpertPolicy.json`；前五档名称、反应参数、旧策略文件与原有购物实现保留。默认仍为普通。ESC暂停页支持数字1～6、鼠标与手柄十字键；联机由房主在大厅选择。不会因为切档赠送血量、伤害、金币、技能等级或冷却。

## 感知与公平约束

宗师每0.06秒记录一次公开可观察快照，快照须等待0.18～0.24秒，才可参与决策；动作决策间隔至少0.18秒。延迟包括敌人位置、从历史位置估计的速度、公开HP/K与抬手、飞弹/陨石警示、柱子、场地边界，以及自身受击、击退和位置。自身位置用延迟观测速度有限外推，不直接读取新受击后的现场位置来瞬时闪避。隐身对手遵守已有100距离可见条件。施法仍走正常前摇、伤害、冷却和碰撞。

模型不能改变感知队列或最低延迟。执行技能时，权威规则仍会拒绝不合法的动作。已有动作的施法计时与物理碰撞正常执行，不把动画或碰撞本身误称AI反应；预定的闪现接天罚也保留至少180ms衔接间隔。假动作通过实际抬手与取消实现，不能取消已经释放的投射物。

## 学习范围

采用独立的64特征、61行参数的多头线性Actor-Critic，包含技能/假动作/连招、九方向走位、三类瞄准和合法购物/效果模式四个选择头。不是五档旧模型改名，也不是端到端深度神经网络。策略权重实际更新，仍保留人工提供的合法性掩码、基本先验与安全约束。

走位候选评估0.18/0.4/0.7秒的相对轨迹风险，避开可观察飞弹、范围预警、柱子与岩浆，并尝试占据对手靠场地中心一侧的位置，向外施压。发现途中折返撞弹后，改为角色/飞弹相对运动扫掠，并在安全路径允许时保持约0.55秒闪避方向；遇到更危险的新路径可打破承诺。不同技能使用各自射程/速度/落地延迟估计瞄准，走位可绕过线性预判。疾风步期间缩短接近距离，位移、换位、回溯、二次闪现、镜像与沉默限制按技能规则处理。

购物与模式选择只在准备阶段执行，所有购买经同一个 `Price/Buy/SetSkillMode` 权威接口，遵守金币、前置、容量、上限和技能槽互斥。使用既有21个可购买技能族、精通和八类已实现物品。训练使用20～200金币的合法构筑课程，双方起始预算相同；正式比赛仍按原图默认20金币开局，不把训练课程写成游戏奖励。

## 快速训练与选模

复用真实UE固定步战斗，NullRHI关闭渲染，每批推进128个0.03秒步；小模型CPU训练/推理，无需Python训练服务、PyTorch或GPU。最多两个UE评估进程并行；使用显式日志和输出目录。训练时的陨石延迟仍量化到固定步，镜像位置也随训练步推进并在每局清理。

首阶段种子103091，360秒采样预算完成2410局、2474333次更新，累计189166.17秒模拟时间。对手混合保留的第五档与冻结的宗师快照，最多保留五份，避免边训练边改变同场对手权重。该阶段已延迟对手和威胁感知。

随后补齐自身受击/位置延迟，并用种子113091进行600局适应训练，采样77.92秒，累计更新至3087987。不能把首阶段修正前的91.2%留出胜率当作最终运行版本的胜率；最终模型依据修正后的同种子选模与新留出结果选择。原始训练与选模文件保留在 `Saved/Training/expert-*`，精简证据、最终模型SHA及胜负数记录在 `Docs/AITraining/2026-11-27-expert.json`。

## 验证与复现

`verify_iteration13.py` 运行原有638项、五档兼容17项与宗师感知/购物检查；新增用例覆盖前150ms不行动、不提前读取目标新位置、自身受伤不能150ms内瞬时开盾、真实火球无伤闪躲、岩浆边缘返回和合法装备购买。`verify_expert_packaged.py` 验证真实玩家包加载新模型、四席战斗与三个宗师的最低观测年龄。联机脚本可加 `--difficulty 6`，验证服务器接受并复制第六档。

最终678项PIE集成检查通过，其中宗师23项；原规则/输入/经济/技能638项保留。旧推理用例修正为推进真实决策时钟：暂停中重复调用Think会令正常的NextDecision永远等不到，不能把这种测试夹具错误判成策略未执行。六档菜单截图已检查，无标签截断，显示模型加载和至少180ms提示。实体手柄与真人对局尚未验收。

最终Windows玩家包四席检查4项通过（模型加载、四席实战、三名宗师决策和最低年龄），远端Linux专服＋两包97项通过，含第六档复制、八席设置、购买、位移/柱子、伤害/击退、金币/胜利、断线/重连和两个服务端宗师的四席实际施法。原始记录分别为 `Saved/Validation/expert-packaged/report.json` 和 `Saved/Validation/network-20261127-172653/report.json`。未重新认证4K/120FPS，不把本轮AI功能验证当作画质/帧率达标。
