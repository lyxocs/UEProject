# 准备、设备分配与 AI 战术

2026-11-26。本轮是开发版体验迭代；伤害、价格、金币、冷却与击退公式继续使用原地图基准。AI 战术、界面与环境表现属于开发决策。

## 准备与操作

准备阶段每个真人视口顶部都有“准备完毕”按钮，也可按空格或手柄 Y。再次按可取消准备；购买成功会取消该玩家的准备。AI 默认就绪。所有真人就绪后立即进入战斗，保留开局40秒、后续30秒的超时开局机制。下一轮或重开会重新要求真人准备。战斗时 Y 恢复对应技能。

| 模式 | P1 | P2 | 切换 |
|---|---|---|---|
| 单人 | 键鼠或第一只手柄 | 无 | 启动 Solo |
| 混合双人 | 仅键鼠 | 仅第一只手柄 | 准备阶段 F3 |
| 双手柄 | 仅第一只手柄 | 仅第二只手柄 | 准备阶段 F2 |
| 键盘/鼠标拆分 | 仅键盘 | 仅鼠标 | 准备阶段 F8 |

输入在视口层按手柄编号分配，并在控制器层再次过滤设备；未分配的手柄不回落到 P1。切换模式清空按键、摇杆缓存、移动目标与 Enhanced Input 映射状态。Esc/Menu 保留全局暂停。

战斗底栏使用独立缩放的紧凑布局：八技能横排、较小的生命/K与金币面板，去掉常驻全部技能名称。鼠标专属玩家保留当前选中技能名称与点击选择；商店保留完整说明。头顶血条底部避让范围同步缩小。

## AI 的可读战术

- 保留已有约0.45～0.75秒观察延迟，不读取玩家按键来即时反制。目标换人或观察到闪现后重新等待。
- 偶尔抬手施放天罚或陨石，在0.20～0.32秒后走正常取消路径，不扣血、不进入冷却；假动作间隔9～14秒。
- 已学闪现且冷却可用时，可以向目标此前观察位置前方约135单位落地，停顿0.12～0.22秒，再接正常0.7秒前摇的天罚。连招间隔11～17秒，落点与施法位置检查安全区。闪现被取消不会补天罚。
- 连招提交后不持续追踪玩家最新位置；玩家移动或闪现可以让它打空。施法仍受正常伤害、自损和冷却约束。
- 走位方向保持2～4秒，减少原地左右抖动；根据观察到的移动估计有限提前量。只对未来约0.6秒内逼近的敌方飞弹尝试避让，不躲已经远离的飞弹。

主要实现位于 `WarlockAITactics.cpp`、`WarlockInput.cpp`、`WarlockMatch.cpp` 与 `WarlockHUD.cpp`。当前是轻量状态机，仍不是完整难度分级、学习型 AI 或所有技能组合。

## 动态画面

在已有流动岩浆、技能火焰/电弧/残影基础上，竞技场边缘加入24个低亮度、缓慢漂移和升起的余烬。随安全区变化调整环绕位置，不增加碰撞、伤害或投影光源。岩浆从均匀霓虹轮廓调整为扭曲、断续热缝，分层噪声控制冷却壳、裂缝宽度和热度，并保留慢速流动。保留现有 Lumen、阴影与角色材质，不引入付费资源。当前仍是样机美术，正式高清角色与完整场景建模范围见第12、16章。

`Scripts/polish_arena_ambience.py` 仅通过编辑器修改自有岩浆材质的现有 Custom 节点，使用版本元数据避免重复修改，已验证第二次运行更新数为0；不删除材质表达式或改写二进制文件。
