# 本地玩家、设备认领和键盘改键

Esc/Menu暂停菜单新增「本地玩家」（F9）与「键盘改键」（F10）。原画面设置和AI强度页保留。此处为本机离线对局设置，不支持联网房间中增减真人席位。

## 人数与加入

- 选择单人或双人；双人立即创建两个LocalPlayer并应用左右分屏。
- 依次提示P1、P2使用想要的设备确认：手柄A，键盘Enter，也可点击使用键盘鼠标加入。当前席位显示确认提示，另一侧显示等待／已加入状态。
- 一套键盘鼠标视为一个设备；每只手柄按当前运行中引擎报告的槽位识别。允许P1手柄／P2键鼠、P1键鼠／P2手柄及双手柄按任意先后顺序认领。设备不能同时占两席，重复确认会提示并继续等待另一设备。
- Backspace、Esc或手柄B回到上一个认领步骤；首个步骤回退则取消认领、回到人数页。取消认领保留当前人数和安全设备分配，不恢复已重开的旧对局。完成后仍暂停，Esc/Menu继续。
- 人数变化立即重开对局，界面明确提示；生命、金币和积分按新比赛初始化，保持已设置的总参战人数。双人切回单人销毁第二个本地控制器／角色并补一名AI。人数不变时重选设备不重开，不清空原回合、金币和生命。总参战人数现可设2～8，默认4，详见[第25章](25_ParticipantCount.md)。
- 设备方案只在本次运行中有效，不把另一台PC或下次启动的序号当作同一只手柄；本轮未实现物理手柄断线／重连自动认领保证。

原F2双手柄、F3键鼠P1加手柄P2、F8键盘P1／鼠标P2分开仍在准备阶段有效；F5可临时切换上下布局，新人数选择统一回到左右分屏。现有四种批处理启动入口保留。

输入按每个控制器的LocalControl和LocalPadIndex查找所属席位，不再用P1角色推测全局设备映射。鼠标按钮／轴和键盘分别查找所有者，手柄按显式槽位查找，支持反向混合与双手柄。全局Esc和设备管理快捷键保持可用。

## 改键

22项单键：上下左右移动、8技能、商店、停止／取消、准备、购买确认、技能模式、替代路线、出售、乔丹之石、外观与指南。点击操作，或方向键选择后Enter/A，接着按新键。上下选行、左右换列；Esc/Backspace或手柄B取消录入，有恢复默认按钮。

已占用的键与该操作的旧键交换，保持一键一项。系统键Esc/Backspace、控制台键、F2～F10、翻页键和修饰键保留；鼠标、手柄和组合键不在本轮键盘单键编辑范围。菜单自身Enter、方向键、Backspace固定，避免返回或确认被改丢。

UGameUserSettings保存KeyboardBindings，供本机拥有键盘的席位使用。改键修改现有EnhancedInput映射并冲刷按住状态，保留手柄／鼠标映射；移动轮询与商店导航读取同一配置。技能栏、准备、商店操作和指南同步显示。改键不改变技能数值、冷却和经济。

认领／录入期间拦截战斗输入；提交后清空移动、点击目标、待释放动作和按键缓存，确认键不会带入下一次技能。暂停中按下的战斗键不会在恢复后补发；验证脚本按先恢复再按键、先释放再暂停的真实操作时序执行。
