# 整体视觉与准备练习

2026-11-27，用户授权整体优化人物动作、场景配色、UI和特效，并明确要求准备阶段可以移动、施法、互相击退而不造成伤害。本轮准备规则是用户要求的 UE 改动，不冒充原地图默认行为；正式战斗伤害、冷却、经济和碰撞不随美术改变。

## 场景与角色

四套场景配色按回合轮换：余烬玄岩、月影银灰、古铜苔石、暮光紫岩。准备阶段预览下一回合，进入战斗保持该主题；结果阶段保持本轮主题，下一次准备再缓慢过渡。由复制的回合和阶段计算，各客户端不用独立随机数。`UWarlockPresentation.Palettes` 保存名称、石材、岩浆核心、岩浆边缘和装饰颜色。默认1.4的指数插值约两秒接近新色，不突然整屏换色。

岩浆在全部主题中保持暖色危险提示，敌我生命条和技能的元素配色独立于环境主题。材质变化不控制安全半径。增加无碰撞边界环，跟随实际 `ArenaRadius`，沿内侧约0.5%描线；缩圈使用原来的权威查询。

石材改为更细、更浅的接缝和克制的矿物变化，减少粗黑多边形割裂。岩浆增加不规则流动、冷壳与局部热斑，降低整面霓虹裂线感。照明改为中性偏冷主光、较充分的环境填充，降低Bloom与暗角；保留Lumen、阴影和原画质档位。三套术士衣料提高暗部辨识度，保留酒红、藏蓝、墨绿和不同金属配色。

本轮沿用派生细化的原术士网格及51骨骼，不是重新制作高精度人物。没有购买素材包，没有声称已达到最终次世代美术目标。

## 动作、特效与UI

- 所有技能继续有可取消的真实前摇。按技能区分抬手起始、全身混合强度和收势；天罚、流星使用重施法的下落动作，飞弹保留向前释放。前摇时长和释放事件不改。
- 人物模型增加轻微移动倾斜、施法扭转和受击后仰；只改变Avatar，不改变根节点、移动速度或碰撞。受击短暂暖色闪亮，0.18秒淡出，跟随权威命中序号复制。
- 天罚／命中使用专用冲击环，流星使用专用危险预告。重施法蓄能从地面汇向法杖，闪电采用快速竖向电荷环，闪现采用更宽的轨道。命中火星沿击退方向偏移；火球主体降低叠加过曝。
- UI使用更暗的底色与细金属收边，战斗回合标题缩薄并显示当前场景主题。准备阶段显示即将进入的回合编号。急行有独立风形图标，折跃／齐射在紧凑技能栏显示模式标记；K达到30／70时用橙／红提示危险。
- 左右分屏、独立商店、鼠标玩家点击技能和暂停界面保留。没有放大战斗技能栏。没有新增投影点光源，沿用既有粒子池数量，边界只增加一个平面组件。

材质脚本 `Scripts/polish_visual_direction.py` 通过UE资产接口修改项目拥有的节点，版本标记防止重复加节点；新资产在 `Materials` 中。正式烘焙必须使用完整Cook。`Scripts/CaptureVisuals.ps1 -Round 1..11` 可做受控主题截图，不代表自然完整对战。

## 准备阶段练习

准备阶段继续采用0.03秒权威步，推进移动、前摇、投射物和锁链。命中产生原来的冲量和练习K，但不扣生命、不产生击杀／助攻积分或金币；天罚免除自身生命消耗，岩浆与撞柱不扣血，柱子不被打坏。合作队友此阶段也可互相击退，正式开战恢复原友伤限制。机器人默认准备，不主动在准备阶段攻击。

打开商店立即停止主动移动、点击移动和待发施法；其他玩家仍可击退正在购物的人。关闭商店后恢复控制。超出安全半径400单位时安全返回内圈并重置练习状态，不收费。战斗开始销毁练习飞弹和视觉事件，重置生命、K、动量、冷却、待发技能与临时效果，恢复4秒保护；旧延迟流星由回合代号失效。

准备超时和所有真人准备后立即开战保持不变，AI仍默认准备。键盘空格准备；手柄关闭商店时↑准备、Y练习火焰喷射，打开商店后Y准备、↑导航商品。鼠标玩家可点击准备按钮。战斗八技能键位不变。
