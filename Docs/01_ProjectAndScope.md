# WarlockArena 项目目标和版本范围

## 核心体验

玩家以俯视角控制术士，在被岩浆包围、逐渐缩小的竞技场中施法。攻击既减少生命，也累积独立的击退值；随着击退值增长，同样的法术会将目标推得更远。玩家在回合之间购买新技能、升级已有技能、精通和装备，构建自己的组合。

需要还原的是预判弹道、站位、连招、位移自救和构筑节奏。画面升级不能牺牲技能可读性；特效亮度与复杂度不能遮住人物、弹道、柱子和安全边界。

用户要求正式游戏达到次世代视觉品质，包含现代光影、材质、角色动画与法术表现。Warcraft III只作为规则与数值基准，不作为画质上限。技术原型先灰盒验证，首版交付需要有正式品质竞技场，详见 [次世代画面和光影](11_VisualQualityAndLighting.md)。

## 完整目标

- 原版 G/F 基础能力，以及 D、R、T、E、C、Y 六槽的 21 个技能族；保留原版的同槽互斥和有实际实现的模式。
- 13 类战斗物品及其升级、互斥、出售、背包、乔丹之石；三类精通与博而不专。
- 原版普通回合模式的 FFA 和固定队伍对战，包括死亡观战、结算、回合间购买、终局与加赛。
- 固定步移动和外力模拟、弹道交互、柱子、岩浆、安全区域与缩圈。
- 保留 12 玩家数据容量；先验证小规模联机，再扩大人数，不在首版承诺匹配服务或高并发服务器。
- 原版存在四种角色，差异集中在 F 及其联动：术士、邪教徒、审判者、秘术师。完整版本逐个核对，不将模型内部名当成玩家可见名称。
- 支持参战机器人；支持同一电脑两名玩家分屏、各用一个手柄，能彼此对战或一起对抗机器人。输入、镜头、商店和HUD按玩家隔离，详见 [机器人与本地双人](09_AIAndLocalMultiplayer.md)。

原版同时存在死亡竞赛、化身者、国王及其他特殊模式、地图设置命令、外观与令符。数据和入口应留档；这些不属于第一版普通回合玩法的验收范围。完整扩展模式需要独立的规则确认与规格补充，不能仅更改胜利条件就宣称还原。

## 第一版默认范围

以下是用于继续开发的默认方案，不是声称用户已逐项确认的偏好。后续用户改变人数、操作或联机目标时，修改范围和实现计划，不修改原版参考数据。

| 项目 | 第一版交付 |
|---|---|
| 平台 | Windows 桌面，键鼠与手柄；本地双人使用两个独立手柄 |
| 游玩方式 | 单人对AI、本地双人分屏及双人加AI；保留2～4席直连网络房间，总席位含AI |
| AI | 首版标准难度，合法移动、施法、躲避、自救、购买与完整回合循环 |
| 本地双人 | 同进程两名本地玩家，默认上下分屏，可切左右；独立输入、相机、HUD和商店 |
| 角色 | 普通术士一种，使用该角色 G/F 规则 |
| 视角与操作 | 俯视镜头；键鼠沿用点击移动与指向施法；手柄左摇杆移动、右摇杆瞄准，映射见新增章节 |
| 场地 | 一张完整竞技场，含安全地面、岩浆、缩圈与柱子；技术阶段灰盒，交付阶段采用正式材质与光影 |
| 技能 | G 火球、F 天罚；D 闪电、R 瞬间移动、T 火焰喷射、E 流星、C 反射盾、Y 锁链 |
| 模式 | 首个可玩闭环每技能只开放第一模式；完整首版验收再补入该组技能的原有切换模式 |
| 经济 | 原版默认金币与技能购买流程；精通、背包与首版相关装备逐步接入 |
| 物品 | 首版完整验收开放原物品第一页八项；其他物品随后按原规则扩展 |
| 结算 | 普通回合FFA及双人同队对AI；积分、11回合终局和同分加赛 |
| 表现 | 次世代画面目标：统一材质、角色、现代光影与法术特效，同时保证命中、危险区域与双分屏可读性；占位仅限开发阶段 |

最早的技术样机可以少于上述技能，但不能作为第一版完成交付。首版暂不开放的内容必须在 UI 和配置中明确关闭，禁止出现可购买却没有效果的条目。

## 暂不包含的产品功能

账号系统、公开匹配、排名赛、付费外观、云存档、跨平台、移动端、外部LLM机器人、原地图的名字白名单和权限余额不进入首版。首版不要求分屏玩家再连接其他电脑的混合网络房间。网络传输方案先选可验证的直连方式；公网穿透、Steam 或其他在线服务在需求明确后再接入。

## 美术与资产

原地图提供规则与行为参考。开发初期使用自建占位资产，正式首版将样板画面的品质扩展到完整竞技场；美术使用项目自有或有可用授权的资产。文件中存在模型和音频不等于已经确定可用于独立发布。资产替换不允许改变实际碰撞体、命中范围或危险区判断。

角色可见大小、真实受击半径和特效范围分别配置。视觉上“落入岩浆”必须与逻辑地面查询一致。固定相机需要让所有参战位置和安全边界可读，不用摄像机晃动代替命中反馈。
