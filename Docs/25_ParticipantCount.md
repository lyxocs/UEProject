# 2～8人参战设置

用户新增：ESC可调整总参战人数，最多8人，覆盖旧版固定4席的实现范围。本地分屏仍为1～2人，其余由AI补齐；不是8人本地分屏，也不表示已验证8台联网PC。

Esc/Menu → 本地玩家 → 总参战人数（含AI），点击−/+，或PgDn/PgUp、手柄LB/RB。默认4，可选2～8，显示当前AI数量。真人合作至少保留一个AI对手，本地双人合作最低3人；FFA双人可以没有AI。改变总人数重开比赛，恢复生命／初始金币并清理飞弹和技能；重复选择当前人数不重开。认领设备期间不能同时改总人数。

手动选择保存在本机GameUserSettings的WarlockRoster.Participants，重启恢复。MatchState.ParticipantCount由权威模式维护并复制；本轮ESC变更仅支持本机离线对局。原本地单／双人、反向设备、改键、准备和AI五档保留。改变本地人数保持总人数并重新补AI；合作自动下限调整是当前运行的约束。

EnsureRoster按目标增减AI并处理角色／控制器，保护真人席位；机器人重编号，避免反复增减后重名。准备和开战按2π/N均匀布置出生点，4人仍是原四向位置，8人不会重叠在4个位置。半径700、碰撞、场地、技能、经济、保护和缩圈公式不重新平衡。名单显示当前/总数并容纳8行。原地图只读；旧模型在8人可推理，但没有对8人重新训练或校准胜率。

新增54项真实PIE检查：2～8所有人数、AI数量／就绪、名字／队伍唯一、出生间隔、无残留控制器、暂停限制、上下限、键盘／手柄操作、八人保护／AI策略／胜负、重开清理、合作下限及真人变化。相关本地改键44、设备24、准备36、完整11轮／加时88项重新通过，合计246项。测试AI策略时单独去掉了机器人的开场保护，正式游戏原有4秒保护没有改变。物理手柄、持续高负载和8台联网PC未验收。

独立Windows进程25项检查通过，包括8人设置落盘、实际重启MatchState仍为8、新安装默认4、原画质与改键保存，共271项相关检查。Editor/Game完整编译与Windows打包通过；实际查看单人/双人ESC菜单及八人战斗，未见致命错误或材质回退。菜单为启动即暂停的布局截图，FPS含启动耗时，不作性能依据。
